08 · Rules

Do's & Don'ts

Do
  • Use IvyJournal weight 300 for all financial figures
  • Keep border-radius at exactly 0px throughout
  • Keep gap between cards at 0 — flush grid only
  • Use opacity as hierarchy (100% → 45% → 30%)
  • Write card labels in UPPERCASE with 0.18em tracking
  • Use the defined color tokens — never ad-hoc hex values
  • Apply grain overlay on all pages via body::before
  • Stack animations with 0.05s stagger increments
  • Use cubic-bezier(0.22, 1, 0.36, 1) for all motion
  • Use dark text (#1a1208) on gold cards, not cream
  • Load both fonts in <head> before any CSS
  • Keep chart borders at 0 and grid lines near-invisible
Don't
  • Add border-radius to cards, inputs, or buttons
  • Add box-shadow or glow effects to any element
  • Use Space Grotesk for large financial figures
  • Use white (#FFFFFF) as a background — always near-black or variants
  • Place the Tesoro logo on a light background
  • Use more than 2 typefaces in the same page
  • Increase grain overlay opacity above 0.04
  • Add gutters between cards in the grid
  • Use bold weight numbers anywhere in the UI
  • Write "ivyjournal" with a hyphen (CSS name breaks)
  • Use emoji in any UI text or label
  • Add exclamation marks or congratulatory copy
